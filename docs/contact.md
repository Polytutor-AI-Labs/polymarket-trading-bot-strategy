# Contact PolyTutor

**Polymarket bots · Strategy automation · Trading infrastructure**

> Have a Polymarket strategy you want to automate, an existing bot you want to improve, or an execution problem you want to solve? Send PolyTutor a project request with the market, strategy idea and required behavior.

> Trading systems involve risk and future performance cannot be guaranteed.

## Request a Bot

> The fastest way to start is to open a structured Bot Request. You do not need to provide a complete technical specification — a manual trading workflow or high-level strategy is enough to begin a feasibility discussion.

[Request a Bot →](https://github.com/polytutor-labs-handbook/polymarket-trading-bots/issues/new?template=bot-request.yml)

On GitHub: **Issues → New issue → Bot Request**.

## Public vs Private Communication

**GitHub Bot Request** is appropriate for non-sensitive project descriptions. GitHub Issues may be publicly visible. Do not post private strategy details, commercial terms, proprietary code, or anything you do not want public.

**Direct Contact** is preferred when the project contains private strategy information, commercial terms or proprietary code.

Credentials are never required for initial project evaluation. See [SECURITY.md](../SECURITY.md).

## A Good First Message

Include:

- target market
- strategy summary
- entry idea
- exit idea
- risk requirements
- whether code already exists
- expected deployment
- timeline

> You do not need to know the final technical architecture. PolyTutor can help turn a trading workflow into a technical specification.

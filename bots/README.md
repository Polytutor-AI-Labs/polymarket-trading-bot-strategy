# Bot & System Research

This directory presents system-level research areas for Polymarket and prediction-market engineering.

A strategy describes a market hypothesis. A trading system combines strategy logic with data ingestion, validation, risk management, execution, and position management.

These pages are conceptual. They are not implementation guides, not source-code documentation, and not claims of profitability or production readiness. Every system below is **Research**.
